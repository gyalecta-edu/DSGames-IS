# Deliverables DS Games

La distribuzione mantiene `pom.xml` e `src/` nella **radice del repository** per consentire la compilazione Maven standard. Gli artefatti di progetto e di verifica si trovano in `docs/`:

- `docs/IMPLEMENTAZIONE_DSGames.md`: tracciamento di funzionalità e moduli.
- `docs/TESTPLAN_DSGames.md`: test e casi di verifica.

**Nota:** i documenti formali `PS_DSGames`, `RAD_DSGames`, `SDD_DSGames`, `ODD_DSGames` e i report test approvati dal docente non sono compresi nei materiali di partenza. Non vengono simulati o attribuiti al docente. Per la consegna del corso IS devono essere integrati con le versioni effettivamente concordate.
